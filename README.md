# Frontend Mentor Challenges

Solutions to coding challenges from [Frontend Mentor](https://www.frontendmentor.io/), built one at a time across all five difficulty tiers — newbie through guru.

Each challenge lives in its own folder, named after the challenge. Difficulty tier, stack, and live link are tracked in the table below rather than in the folder structure — tier describes the challenge, not what was actually built, so it's metadata here, not an organizing principle.

## Live demos

Completed challenges are published from a single GitHub Pages hub in this repo (`/docs`), which links out to each challenge individually. Vanilla challenges are served directly; challenges built with a framework are built and published from the same hub.

## Stack

Varies per challenge — some are plain HTML/CSS/JS, others use React, depending on what the challenge calls for. Each challenge's own README states what was used and why.
